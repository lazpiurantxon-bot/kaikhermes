# Spec — EZTI Sprint 1: shortlist de copackers y compliance v1

- **Estado:** BUILD (parcial completado 2026-07-06)
- **Riesgo:** R0 (investigación) con salida a R3 (envíos de contacto, gateados)
- **Owner:** Analista de Investigación → Estratega

## Objetivo

Desbloquear el camino crítico de 90 días de EZTI: fabricante/copacker cerrado.

## Criterios de aceptación

1. ≥8 candidatos identificados con fuente, tipo y motivo de candidatura → **✅ 12 candidatos** (`knowledge/ezti/proveedores.md` v0.1)
2. Dossier de compliance alimentario v1 con fuente primaria por norma y flags de asesor → **✅** (`knowledge/ezti/normativa-alimentaria.md`)
3. Borradores de contacto ES/EN listos para gate → **✅** (`domains/ezti/outreach/`)
4. Segunda pasada: envasadores de miel con línea monodosis + verificación de fichas → ⬜ pendiente
5. 5–6 candidatos priorizados y gates R3 solicitados al propietario → ⬜ pendiente
6. Tras respuestas: tabla de scoring completada y memo de decisión (≤3 finalistas) → ⬜ pendiente (depende de 5)

## Kill-criteria

Si tras contactar ≥8 candidatos ninguno acepta MOQ compatible con el presupuesto de primer lote, el memo debe presentar alternativas honestas: (a) subir volumen/inversión — decisión del propietario; (b) envasado semiartesanal con obrador local registrado; (c) replantear formato.
